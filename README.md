# Amorino site model

Interactive 3D model of the section and the Amorino house, with design options for the deck, front lawn, and entrance. The buttons under Designs switch between the existing house and each design, which is shown on its finished ground; a design can be linked directly, for example `index.html#raised-lawn`. Levels are RL on the datum of the 2010 consent plans (upper floor 100.00) and are uncertain by about ±0.3 m until surveyed.

The page is built in a separate private repository and copied here by its export script, so changes belong there rather than here.
