# 39 Amorino Drive site model

Interactive 3D model of the section and house at 39 Amorino Drive, Red Beach, with design options for the deck, front lawn, and entrance. `index.html` shows the existing house and site; each page in `designs/` shows one design on its finished ground. Levels are RL on the datum of the 2010 consent plans (upper floor 100.00) and are uncertain by about ±0.3 m until surveyed.

The pages are built in a separate private repository and copied here by its export script, so changes belong there rather than here.
