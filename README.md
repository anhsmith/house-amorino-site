# Amorino site model

Interactive 3D model of the section and the Amorino house, with design options for the deck, front lawn, and entrance, and roofs for the rear deck. The buttons under Options set every choice at once (the existing house and each named plan), and each choice can then be changed; a design is shown on its finished ground. The choices are kept in the link, for example `index.html#north=on&entrance=bed2`. Levels are RL on the datum of the 2010 consent plans (upper floor 100.00) and are uncertain by about ±0.3 m until surveyed.

The page is built in a separate private repository and copied here by its export script, so changes belong there rather than here.
